# Plannen voor de volgende versie (4.2)

Pas bouwen als de gebruiker "bouw 4.2" zegt.

1. Rij **Nieuws** met NOS, NU.nl, AD, De Telegraaf, NRC, de Volkskrant, RTL Nieuws en Het Financieele Dagblad
   (ook in Diensten kiezen).
2. Websites met de afstandsbediening: pijltjes springen tussen links/knoppen (Edge spatial navigation),
   kort Terug = vorige pagina, lang Terug/Home = startscherm, grotere tekst op nieuwssites.
3. **Verder kijken** naast de tegel **Schilderij** in de rij Media (in plaats van een eigen rij).
4. Knop **Aanpassen** wordt **Instellingen** met een tandwiel-pictogram; het menu heet ook Instellingen.
5. **Diensten kiezen** ingedeeld in kopjes: Streaming, Radio, Podcasts (en Muziek).
6. "Radiozender toevoegen…" uit het menu Instellingen halen (blijft via Menu op een zender).
7. **Release-info** net boven "Sluiten" in het menu.
8. "Achtergrond kiezen" wordt **Achtergrond wijzigen**, met een optie om een gratis foto te kiezen
   (zoeken + schermtoetsenbord). Bron: **Pexels API** (gratis sleutel, 200 verzoeken/uur, 20.000/maand;
   gebruik zonder naamsvermelding toegestaan, wel fotograaf tonen). Pixabay verbiedt verspreiding als
   los bestand; Unsplash eist hotlinken en heeft een demolimiet van 50/uur. Pexels-sleutel nodig van de
   gebruiker (pexels.com/api), ingebouwd en versluierd zoals de TMDB-sleutel.
